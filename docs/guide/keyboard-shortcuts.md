Some keys, such as the number keys in the inbox, work only when you aren't typing in a box.

## From any app

| Keys | What it does |
|---|---|
| <kbd>⌥</kbd> <kbd>Space</kbd> | The **Talk hotkey**. Opens the inbox panel on the oldest waiting ask and starts dictation. Press it again to stop dictation. |

To change the Talk hotkey:

1. Open **Settings › General › Zero › Talk hotkey**. To open Settings, press <kbd>⌘</kbd> <kbd>,</kbd> or click the gear at the foot of the window's left rail.
2. Click the button. While it waits for keys, the button reads **Press keys…**.
3. Press the new keys. They must include at least one of <kbd>⌘</kbd>, <kbd>⌥</kbd>, <kbd>⌃</kbd> or <kbd>⇧</kbd>. <kbd>Esc</kbd> cancels.

The new keys work at once. You can't change any other key in Zero.

## In the menu bar icon's menu

Click Zero's icon in the menu bar. These keys work while its menu is open.

| Keys | Item | What it does |
|---|---|---|
| <kbd>⌘</kbd> <kbd>0</kbd> | **Show Zero** | Opens Zero's window. |
| <kbd>⌘</kbd> <kbd>,</kbd> | **Settings…** | Opens Settings in Zero's window. |
| <kbd>⌘</kbd> <kbd>Q</kbd> | **Quit Zero** | Quits Zero. |

## In the inbox panel

The inbox panel opens beside the control bar, on the right edge of your screen. These keys work while the panel has the keyboard focus. The panel gets the focus when you click the bar or press the Talk hotkey. See [The inbox and asks](/docs/inbox-and-asks).

| Keys | What it does |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> | Selects the card above or below. |
| <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> | Picks the first, second or third answer on the selected card. To pick a later answer, click it. |
| <kbd>Return</kbd> | Puts the cursor in the selected card's reply box, or in the agent's message box. |
| Any letter | Starts to type that letter into the selected card's reply box, or into the agent's message box. |
| <kbd>Return</kbd>, in a reply box | Sends your reply. |
| <kbd>⌘</kbd> <kbd>V</kbd>, in a reply box | Pastes. A pasted image goes in as its file path. |
| <kbd>Space</kbd> | Starts or stops dictation. |
| <kbd>Delete</kbd> | Removes the selected card from the panel, once you've answered it. |
| <kbd>Esc</kbd> | Steps back one thing at a time, in the order below. |

Each <kbd>Esc</kbd> does the first of these that applies:

1. Closes the suggestions list in the message box.
2. Closes an open model or project list.
3. Closes the agent's screen in the panel.
4. Stops dictation.
5. Closes the open text box of an answer.
6. Takes back the answer you picked last, while its row is still orange: 2 seconds by default. To change the time, go to **Settings › Composer and inbox › Inbox › Take-back window**.
7. Leaves the box you're typing in.
8. Leaves the agent's view and goes back to the inbox.
9. Hides the panel.

An agent's screen, such as a command's picker, can open in the panel. While it's open, the arrows, <kbd>Return</kbd>, <kbd>Delete</kbd> and letters go to that screen.

## In Zero's window

| Keys | What it does |
|---|---|
| <kbd>⌘</kbd> <kbd>N</kbd> | Opens **New task**. |
| <kbd>⌘</kbd> <kbd>1</kbd> to <kbd>⌘</kbd> <kbd>9</kbd> | Opens the first nine tasks, in the order of the sidebar. |
| <kbd>⌘</kbd> <kbd>,</kbd> | Opens Settings. |
| <kbd>⌘</kbd> <kbd>[</kbd> | Goes back. |
| <kbd>⌘</kbd> <kbd>]</kbd> | Goes forward. |
| Mouse side buttons, or a swipe | Go back and forward, as in a browser. |
| <kbd>⌘</kbd> <kbd>W</kbd> | Closes the window. Zero stays in the menu bar and your agents keep running. |
| <kbd>⌘</kbd> <kbd>Q</kbd> | Quits Zero. Your agents keep running. |
| <kbd>⌘</kbd> <kbd>Z</kbd> | Undo. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>Z</kbd> | Redo. |
| <kbd>⌘</kbd> <kbd>X</kbd>, <kbd>⌘</kbd> <kbd>C</kbd>, <kbd>⌘</kbd> <kbd>V</kbd>, <kbd>⌘</kbd> <kbd>A</kbd> | Cut, copy, paste, select all. |
| <kbd>⌘</kbd> and drag | Moves an integration's icon up or down the left rail. |

In dialogs, <kbd>Return</kbd> presses the main button. <kbd>Esc</kbd> presses **Cancel**. When you rename something, <kbd>Return</kbd> saves and <kbd>Esc</kbd> cancels.

## In a task's composer

The composer is the box at the foot of a task's conversation. See [Tasks and workers](/docs/tasks-and-workers).

| Keys | What it does |
|---|---|
| <kbd>Return</kbd> | Sends your message. While the agent works, the message waits in a queue until the agent's turn ends. |
| <kbd>⌘</kbd> <kbd>Return</kbd> | Sends now. While the agent works, the message goes in at once and steers the agent. |
| <kbd>⇧</kbd> <kbd>Return</kbd> or <kbd>⌥</kbd> <kbd>Return</kbd> | Starts a new line. |
| <kbd>⌘</kbd> <kbd>.</kbd> | Stops the agent's turn. |
| <kbd>⌘</kbd> <kbd>V</kbd> | Pastes. A pasted image or video goes with the message. |
| <kbd>1</kbd> to <kbd>9</kbd>, with the composer empty | Picks that answer on the first ask that the agent sent you through Zero. |
| Any letter, with nothing else to type in | Starts to type that letter into the composer, wherever the window's focus is. <kbd>⌘</kbd> <kbd>V</kbd> pastes into the composer the same way. |
| <kbd>Esc</kbd> | Closes the **+** menu. |

When you type `/` or `@`, a list of suggestions opens:

| Keys | What it does |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> | Moves through the suggestions. |
| <kbd>Tab</kbd> or <kbd>Return</kbd> | Takes the highlighted suggestion. |
| <kbd>Esc</kbd> | Closes the list. |

## In a task's conversation

| Keys | What it does |
|---|---|
| <kbd>Esc</kbd> <kbd>Esc</kbd>, within half a second | Opens the rewind list of your messages. |
| <kbd>↑</kbd> <kbd>↓</kbd>, in the rewind list | Moves through your messages. |
| <kbd>Return</kbd>, in the rewind list | Picks the message to rewind to. |
| <kbd>Esc</kbd>, in the rewind list | Closes the list. On the rewind card, <kbd>Esc</kbd> is **Never mind**. |
| <kbd>Return</kbd>, on a permission request docked above the composer | Picks the first answer of the request. This works only when you aren't typing in the composer. |
| <kbd>Esc</kbd> | Closes the task's details card after you click into it. |

The image viewer opens when you click an image. In the viewer:

| Keys | What it does |
|---|---|
| <kbd>←</kbd> or <kbd>↑</kbd> | Shows the previous image. |
| <kbd>→</kbd> or <kbd>↓</kbd> | Shows the next image. |
| <kbd>Esc</kbd> | Closes the viewer. |

## In a model or project list

These lists open from the chips in the composer, such as the model chip.

| Keys | What it does |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> | Moves through the list. |
| <kbd>←</kbd> <kbd>→</kbd> | Switches between the provider tabs in the model list. |
| <kbd>Return</kbd> | Picks the highlighted row. |
| <kbd>Esc</kbd> | Closes the list. A second click on its chip also closes it. |

|---|---|
| <kbd>⌘</kbd> <kbd>B</kbd> | Bold. |
| <kbd>⌘</kbd> <kbd>I</kbd> | Italic. |
| <kbd>⌘</kbd> <kbd>E</kbd> | Code. |
| <kbd>⌘</kbd> <kbd>K</kbd> | Link. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>X</kbd> | Strikethrough. |
| <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>1</kbd>, <kbd>2</kbd> or <kbd>3</kbd> | Heading 1, 2 or 3. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>7</kbd> | Numbered list. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>8</kbd> | Bulleted list. |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>9</kbd> | Checklist. |

See [Later, scratchpads and loops](/docs/later-scratchpads-loops).

## In a terminal

In a task's terminal, all keys go to the terminal except these:

| Keys | What it does |
|---|---|
| <kbd>⌘</kbd> <kbd>C</kbd> | Copies the selection. |
| <kbd>⌘</kbd> <kbd>V</kbd> | Pastes. |
| <kbd>⌘</kbd> <kbd>A</kbd> | Selects all. |
